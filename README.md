# Chems Gym 24/7

Landing page for Chems Gym 24/7 - 24-hour gym in Whitehaven, UK.

**Live site:** https://chems-gym-24-7-bb2795d108-landing.vercel.app

## About

A sharp red-and-black landing page for a 24-hour gym: full-bleed hero, trust indicators, feature and service showcases, three-tier pricing (day pass, monthly, annual), reviews, and a glassmorphism enquiry form with dynamic SEO meta tags.

## Features

- Full-screen hero with red glow accents and trust indicators
- Day pass / monthly / annual pricing table
- Facility gallery cards and member reviews
- Dark glassmorphism contact section
- Injected Open Graph and Twitter meta tags for sharing

## Stack

- HTML5 + Tailwind CSS (CDN)
- Vanilla JavaScript
- [Lucide](https://lucide.dev) icons
- Google Fonts
- Supabase Edge Function (contact form)
